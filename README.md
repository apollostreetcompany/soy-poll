# SoyPoll

The existing [Soy Sauce Survey](https://soypoll.com/), embedded through Typeform.
This repository is a static GitHub Pages website, published from `main`/root.

`index.html` contains page metadata, the unchanged live Typeform embed, and small
privacy/contact notices. `robots.txt` and `sitemap.xml` provide search discovery.
There are no application dependencies or build commands. Do not submit survey
answers as a smoke test or change Typeform settings to validate this wrapper.

See [AGENTS.md](AGENTS.md) for preservation boundaries and the existing canonical
tracker. First-party visitor analytics, domain email forwarding and enforced
crawler protection remain separate, unverified operational work.
